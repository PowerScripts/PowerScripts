# ⚡PowerScripts
PowerScripts is a collection of open-source scripts including games, pranks and more!
## Games 🎮
### 1. PowerBlock
A fun block game that runs entirely in PowerShell CLI.
```powershell
irm https://raw.githubusercontent.com/PowerScripts/PowerScripts/refs/heads/main/scripts/games/powerblock.ps1 | iex
```

## ⚙️ Prerequisites

- **Operating System**: Windows 10, Windows 11, or Linux/macOS with PowerShell 7+.
- **Execution Policy**: If script execution is blocked in your session:

```powershell
Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope Process
```
